# Contributing

Thanks for your interest in contributing to the Data Structure Visualizer! A few simple guidelines to get started:

- Fork the repository and create a feature branch: `git checkout -b feature/my-change`.
- Make small, focused commits with clear messages.
- Ensure the UI still works by opening `index.html` locally and manually testing the changed flows.
- When your change is ready, open a Pull Request against `main` with a clear description and screenshots if applicable.

Code style
- The project is plain HTML/CSS/JS; prefer clarity over cleverness and keep functions small and well-named.

Reporting issues
- Use Issues for bug reports and feature requests. Fill the provided templates when creating a new issue.

Thank you — contributions are welcome!
